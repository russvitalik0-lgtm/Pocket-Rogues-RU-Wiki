# Changelog

## [Unreleased]

### Added
- **Вкладка "Редактор"** в основном приложении
- **Source Editor** с двумя панелями (`QSplitter`): HTML страницы + CSS темы
- **Сохранение HTML и CSS**
- **Автоматические бэкапы** перед сохранением (до 10 последних версий в `WikiContent/backups/`)
- **Индикация несохранённых изменений** в списке страниц и заголовке вкладки
- **Переключение темы** в редакторе CSS (только если нет несохранённых изменений)
- Кнопка **"Открыть в Вики"** - переход на выбранную страницу
- Кнопка **"Сбросить панели"** для `QSplitter`
- **Черновики редактора** (`DraftManager`, папка `WikiContent/drafts/`):
    - Автосохранение по debounce (5 секунд после последнего изменения)
    - Принудительное сохранение при переключении страницы или закрытии приложения
    - Восстановление при открытии страницы (диалог "Восстановить / Удалить / Оригинал")
    - Автоматическое удаление при возврате к оригиналу
    - Автоматическое удаление после сохранения оригинала
    - Индикация черновиков в списке страниц (📝)
    - Автоматическое удаление при совпадении черновика с оригиналом
- **Подсветка синтаксиса**:
    - **В Source Editor:**
        - `HtmlHighlighter` - HTML (теги, атрибуты, значения, комментарии)
        - `CssHighlighter` - приемлемый CSS (свойства, значения, селекторы, комментарии)
        - Палитра в стиле VS Code Dark+
    - **В `Tips.py`:**
        - `MarkdownHighlighter` - Markdown (левый блок с исходным .md | Заголовки, жирный, курсив, зачеркнутый, инлайн-код, ссылки, маркеры-списков, цитаты, разделители)
        - Палитра в стиле VS COde Dark+
- **Visual Editor (далее VE)** - WYSIWYG-редактор страниц (`QWebEngineView` с `contentEditable`)
    - Синхронизация изменений Source <-> Visual при переключении вкладок
    - Отслеживание изменений в **VE** через `input`-событие
    - Автосохранение черновиков из **VE** *(debounce 5 сек. -> синхронизация в **SE** -> сохранение **SE** в черновик)*
    - Пунктирные рамки у блочных элементов (таблицы, цитаты, инфобоксы)
    - Тёмный/светлый фон `QWebEngineView` до выбора страницы в **VE**
    - **Панель инструментов**
        - Отмена/повтор (undo/redo)
        - Стиль параграфа
        - Форматирование текста
        - Списки + Изменение струтуры
        - Вставка (Insert) - имеют заглушки
            - Таблицы, инфобоксы и т.п.
            - Гиперссылки:
                - Диалог (`LinkDialog` через `QDialog`)
                - Вставка `<a href="...">` в VE
                - Поддержка трёх типов ссылок (`#anchor`, `@page`, `https://`)
                - Автоподбор по готовым страницам (поиск по id и русскому названию)
                - Автоподбор якорей по заголовкам текущей страницы (через `JS`)
                - Удаление ссылки через ввод `None` в поле URL (работает только на выделении)
            - Шаблоны: Notes, Collapsible Block, Perks table
        - Вставка блочных элементов с новой строки

### Fixed
- git отслеживал некоторые персональные файлы, ранее не добавленные в .gitignore
- Постоянное мгновенное создание черновиков при открытии страниц во вкладке **Редактор**

### Changed
- Пути в `EditorPage` используют `pathlib` вместо `os.path`
- Загрузка HTML в редакторе - **без** инъекции кнопок действий (использует чтение с диска, а не `load_html`)
- `Tips.py`: `QTextEdit` заменён на `QPlainTextEdit` для корректной работы `QSyntaxHighlighter`
- `SettingsDialog` избыточно создавал экземпляр `WikiPage` для подсчета страниц:
    - Список страниц вынесен в константу **PAGES_LIST** (`Base.py`)
    - `Wiki.py` использует **PAGES_LIST** вместо хардкода
    - `SettingsDialog` использует **len(PAGES_LIST)** вместо экземпляра `WikiPage`
    - Исправлена ошибка с обязательным theme_manager в `WikiPage`

## [v0.4-alpha] - 2026-10-13

### Added
- **Вкладка "Сохранённое"** с карточками сохранённых страниц
- Кнопка сохранения страниц в верхней панели страницы
- Менеджер сохранённых страниц (`saved_manager.py`, JSON-хранилище)
- Кнопка удаления из сохранённых на карточках
- **Граница вокруг `QWebEngineView`** через обёртку `QFrame` (`#wikiBrowserFrame`)
- Автоматическое связное обновление визуала новых элементов
- **Общий QSS** приложения с тремя встроенными темами (`light.qss`, `dark.qss`, `dark-purple.qss`)
- **`ThemeManager`** - управление темами, сохранение выбора в `theme_settings.json`
- **Логотип в заглушках** пустых списков "Недавние/Сохранённое"
- **Вкладка "Стилизация"** с галереей карточек-превью тем
- **`StylePage`** - карточки-миниатюры приложения для каждой темы
- **Палитры тем** в `ThemeManager` для отрисовки превью
- Клик по карточке применяет тему, активная подсвечивается accent-рамкой
- **Раздельные CSS-темы страниц**: `style-dark.css`, `style-light.css`
- **`--hover-table`** - подсветка строк таблиц при наведении
- Светлая тема страниц с яркими accent-цветами

### Fixed
- Отсутствие видимости звездочки на светлом фоне карточки
- Внутриигровое описание **HomePage** отображалось некорректно (задний фон)
- Некоторые страницы были доступны к пользовательскому открытию и просмотру, хотя не были доделаны (из-за того что обходили автоматизацию добавления в стек)
- Стрелки `QSpinBox` не отображались на обоих темах приложения
- Предупреждение Chromium о пустом `sys.argv`
- Emoji-стрелки в `<details>` (заменены на текстовые)
- Иконки действий (фуллскрин, сохранения) инвертируют свой цвет для светлой темы
- Иконки магического урона не отображались (неверное наименование)

### Changed
- `PreviewCard` (`Latest.py`): поддержка опциональной кнопки удаления (`removable=True`)
- `style.css`: изменен стиль отображения кнопок fullscreen и сохранения
- Виджетам присвоены `objectName` для будущей QSS-стилизации
- Inline-стили заменены на QSS-стили (через `objectName`)
- `#mainTabsList`: вкладки получили фон-плашки, hover и accent-подсветку активной
- `dark.qss`: кол-во акцентного цвета было значительно увеличено
- `#previewCard`: увеличен до `250x195`
- **Миграция на PyQt6** (Qt 6.11, Chromium 140 вместо Chromium 83)
- `QWebEnginePage` импортируется из `QtWebEngineCore`
- Enum'ы PyQt6 используют полные имена
- `exec_()` -> `exec()`
- `WikiPage.load_page`: подмена CSS в HTML в зависимости от темы приложения
- `get_page_preview` - изменены параметры фильтрации: лимит увеличен в 300 символов, обрезка по точке в диапазоне 150 символов с конца, иначе - по пробелу
