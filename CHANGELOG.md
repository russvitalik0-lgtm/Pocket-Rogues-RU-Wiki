# Changelog

## [Unreleased]

### Added
- Вкладка "Сохранённое" с карточками сохранённых страниц
- Кнопка сохранения страниц в верхней панели страницы
- Менеджер сохранённых страниц (`saved_manager.py`, JSON-хранилище)
- Кнопка удаления из сохранённых на карточках
- Автоматическое связное обновление визуала новых элементов

### Fixed
- Отсутствие видимости звездочки на светлом фоне карточки

### Changed
- `PreviewCard` (`Latest.py`): поддержка опциональной кнопки удаления (`removable=True`)
- `style.css`: изменен стиль отображения кнопок fullscreen и сохранения

## [v0.3-alpha] - 2026-10-11

### Added
- Страницы **Игровых классов**: Воин, Лучник, Берсерк, Охотник, Маг
- Страница **Лагерная Обитель**
- **Полноэкранный режим** для страниц (скрытие прочих панелей, расширение окна страницы)
- Улучшенное превью в **"Недавние"** (без мусора из инфобоков и кусков текста)
- Стабильное требуемое **центрирование текста** в существующих таблицах (изменение приоритета `.text-center`)
- Необходимые **медиа-файлы** (изображения)

### Fixed
- Пустое пространство в таблицах не имело **accent-цвета** (background таблиц)
- Некоторые таблицы отображались некорректно
- Многие картинки не отображались

### Changed
- `style.css`: акцентные темы для каждой страницы
- `load_page`, `link_interceptor`: инжекция кнопки фуллскрина
- `wizard.html`: рефакторинг страницы Мага
- `Wiki.py`: теперь пользователю доступны только завершенные страницы
- Убран `draggable` с картинок и иконок

[v0.3-alpha]: https://github.com/russvitalik0-lgtm/Pocket-Rogues-RU-Wiki/compare/v0.2-alpha...v0.3-alpha

## [v0.2-alpha] - 2026-10-10

### Added
- Страница **Некроманта** как основа последующим страницам Игровых классов
- Инфобок на странице **Некроманта**
- Перехватывание ссылок из интерактивных гиперссылок с последующей фильтрацией
- Создание общего **CSS** для всех страниц
- Добавлен README.md с инструкцией по установке зависимостей
- Страница **Некроманта** получила свои картинки

### Fixed
- **HTML** и **CSS** некорректно отображались на страницах
- Использование гиперссылок иногда открывало браузер прямо внутри **QWebEngineView** (окна страницы)
- Изображение **Pocket Rogues** не загружалось с полностью рабочим интернетом

### Changed
- Временно удалена недоработанная система **Дополнений**
- Временно убрана вкладка **"Обратная Связь"**
- Временно убрана вкладка **"Сохранённое"**
- `Wiki.py`: поле страниц заменено (`QTextBrowser` -> `QWebEngineView`)
